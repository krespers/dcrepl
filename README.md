# 디시 나만보이는메모장

**메모장 켜라.** 디시 댓글란에 나만 보는 메모를 남길 수 있습니다. 메모는 이 Chrome에만 저장·표시되고 다른 사람에게는 보이지 않습니다.

메모는 게시물별로 이 Chrome의 `chrome.storage.local`에 저장됩니다. 확장 프로그램에는 서버 전송 코드가 없으며, 디시인사이드의 실제 댓글 입력창과 등록 버튼을 사용하지 않습니다.

## 설치

1. Chrome 주소창에 `chrome://extensions`를 입력합니다.
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 눌러 이 폴더를 선택합니다.
4. 이미 열어 둔 디시인사이드 게시물이 있다면 새로고침합니다.

코드를 수정한 뒤에는 `chrome://extensions`에서 **디시 나만보이는메모장** 카드의 새로고침 버튼을 누르고 게시물도 다시 새로고침해야 변경 사항이 적용됩니다.

## 사용

디시 나만보이는메모장에 등록한 댓글은 디시 댓글 목록의 마지막 댓글 다음에 표시됩니다. 댓글 목록이 없는 게시물에서는 나만 보는 입력창 위에 표시됩니다. 나만 보기 모드가 켜져 있으면 사이트의 실제 댓글 입력창은 화면에서 접힙니다. 닉네임과 내용을 적고 **나만 보기 등록**을 누르거나 Enter를 누르면 이 Chrome의 해당 게시물에서만 보입니다. 다른 사람에게는 보이지 않습니다. Shift+Enter는 줄바꿈입니다. 수정과 삭제도 할 수 있습니다. 아직 등록하지 않은 글도 같은 게시물로 돌아오면 이어 쓸 수 있습니다.

확장 프로그램 팝업의 **나만 보기 모드** 스위치 또는 댓글 영역의 **나만 보기 끄기** 버튼으로 모드를 끌 수 있습니다. OFF이면 원래 댓글 입력창이 다시 나타나며, 그 위의 **나만 보기 켜기** 버튼으로 바로 돌아올 수 있습니다. 모드를 꺼도 저장된 메모는 유지됩니다. 팝업의 **화면 색상**에서 사이트 테마 자동 감지, 밝게, 어둡게 중 하나를 고를 수 있습니다.

확장 프로그램 아이콘은 ON일 때 남색, OFF일 때 회색입니다. 편집 가능한 벡터 원본은 `icons/icon-on.svg`와 `icons/icon-off.svg`이며, Chrome에서 사용하는 PNG 파일도 같은 폴더에 있습니다.

나만 보는 댓글에는 **이 Chrome에만 보임** 표시가 남습니다. OFF 상태에서 디시인사이드의 원래 댓글 등록 버튼을 누르면 실제 댓글이 전송됩니다.

## 기록 삭제

게시물의 나만 보는 댓글 영역에서 **이 글 기록 삭제**를 누르면 그 게시물의 메모와 작성 중인 글을 지울 수 있습니다. 확장 프로그램 아이콘을 눌러 팝업의 **전체 기록 삭제**를 누르면 모든 게시물의 메모와 작성 중인 글을 지울 수 있습니다. 두 기능 모두 버튼을 한 번 더 눌러 삭제를 확인해야 하며, 삭제한 기록은 복구할 수 없습니다. 나만 보기 모드와 화면 색상 설정은 유지됩니다.

메모는 현재 Chrome 프로필의 로컬 저장소에 남습니다. 다른 기기와 동기화되지 않으며 확장 프로그램을 삭제하면 메모도 사라질 수 있습니다.
