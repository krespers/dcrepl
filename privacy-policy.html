디시 나만보이는메모장 개인정보처리방침

시행일: 2026년 10월 17일

디시 나만보이는메모장은 디시인사이드 게시물에 사용자 본인만 보는 메모를 표시하는 비공식 Chrome 확장 프로그램입니다.

처리하는 정보와 목적

확장 프로그램은 사용자가 입력한 메모와 작성 중인 글, 메모에 표시할 닉네임, 작성·수정 시각을 처리합니다. 메모를 해당 게시물에 연결하기 위해 디시인사이드 게시물 주소의 갤러리 식별자와 게시물 번호를 사용합니다. 닉네임 입력칸의 초깃값을 표시하기 위해 해당 게시물 화면의 닉네임을 읽을 수 있습니다. ON/OFF 상태와 화면 색상 설정도 저장합니다.

저장 및 전송

위 정보는 현재 Chrome 프로필의 chrome.storage.local에 저장됩니다. 확장 프로그램은 메모와 설정을 개발자, 디시인사이드 또는 다른 외부 서버로 전송하지 않으며, 다른 기기로 동기화하지 않습니다. 같은 Chrome 프로필을 함께 사용하는 사람은 저장된 메모를 볼 수 있습니다.

공유 및 사용 제한

확장 프로그램은 정보를 제3자에게 판매하거나 공유하지 않고, 광고·프로파일링·신용 평가에 사용하지 않습니다. 정보는 게시물별 개인 메모를 표시하고 관리하는 목적에만 사용됩니다. Google API에서 받은 정보의 사용은 Chrome 웹 스토어 사용자 데이터 정책 및 제한적 사용 요건을 준수합니다.

보관 및 삭제

정보는 사용자가 해당 게시물의 기록 또는 전체 기록을 삭제할 때까지 현재 Chrome 프로필에 남습니다. 확장 프로그램 삭제나 Chrome 프로필 데이터 삭제로 기록이 사라질 수 있습니다. 확장 프로그램의 기록 삭제 기능으로 메모와 작성 중인 글을 삭제할 수 있습니다.
